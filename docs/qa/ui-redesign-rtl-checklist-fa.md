# چک‌لیست QA بازطراحی UI Dent — فارسی و RTL

## دامنه

این چک‌لیست برای بازطراحی پوسته، ناوبری، داشبورد، فهرست‌ها، فرم‌ها، پرونده، وضعیت دندان، تقویم، مالی، اعلان‌ها، ورود، نصب و ثبت‌نام عمومی استفاده می‌شود.

## کنترل‌های اجرایی

| شناسه | کنترل | معیار پذیرش | وضعیت |
| --- | --- | --- | --- |
| RTL-01 | ریشهٔ سند | تمام صفحه‌ها `lang="fa"` و `dir="rtl"` دارند. | پیاده‌سازی و regression test افزوده شد؛ بازبینی مرورگر باقی است |
| RTL-02 | دادهٔ ترکیبی | موبایل، FDI، مبلغ، ساعت، URL و شناسه در `bdi` یا `dir="ltr"` خوانا هستند. | آمادهٔ بازبینی |
| RTL-03 | آیکون‌های جهت‌دار | فقط iconهای دارای معنای فضایی mirror می‌شوند. | آمادهٔ بازبینی |
| A11Y-01 | keyboard | Skip link، focus-visible، ترتیب Tab و خروج با Escape کار می‌کنند. | smoke automated در 390px برای Tab/Escape و focus موفق؛ تست دستی screen reader باقی است |
| A11Y-02 | Drawer موبایل | بازکردن focus را منتقل می‌کند، Tab در Drawer محدود است، backdrop و Escape آن را می‌بندند. | open/close، aria state، Tab loop و focus return در 390px موفق |
| A11Y-03 | فرم‌ها | تمام کنترل‌ها label، حالت required، hint و پیام خطای مرتبط دارند. | label/required اصلاح و صفحات اصلی بازبینی شد؛ خطاهای میدانی باقی است |
| A11Y-04 | کنتراست و حرکت | متن معمولی و کنترل‌ها حداقل نسبت 4.5:1 دارند؛ رنگ تنها حامل وضعیت نیست و reduced-motion رعایت می‌شود. | contrast audit توکن‌ها موفق؛ نسبت‌ها 4.75 تا 16.27 به 1 و reduced-motion پیاده‌سازی شد |
| UI-01 | Desktop shell | sidebar راست، گروه‌بندی مجوزمحور، route فعال و header چسبان در 1440 و 1024 درست هستند. | دسکتاپ 1280px تأیید بصری و DOM شد؛ بازبینی 1024px باقی است |
| UI-02 | Mobile shell | بدون scroll افقی ناخواسته در 375 و 768؛ Drawer به‌جای ناوبری افقی نمایش داده می‌شود. | authenticated regression در 375 و 768 موفق و بدون overflow |
| UI-03 | Dashboard | فقط KPIهای واقعی و مجاز Tenant فعال نمایش داده می‌شوند؛ empty state صادقانه است. | regression test و بازبینی بصری دسکتاپ موفق |
| UI-04 | جدول‌ها | header، عملیات ردیف، pagination، empty state و overflow کنترل‌شده در mobile بررسی شوند. | جدول بیماران/فاکتورها دسکتاپ و overflow کلی mobile regression موفق؛ جدول mobile تعاملی باقی است |
| UI-05 | فرم‌ها | login، install، ثبت‌نام عمومی، نوبت، فاکتور، طرح درمان و پیکربندی بالینی بررسی شوند. | آمادهٔ بازبینی |
| UI-06 | بالینی | هشدار حساسیت، پرونده، وضعیت دندان مینیمال و طرح درمان با دادهٔ فارسی قابل‌اسکن باشند. | پرونده و وضعیت دندان‌ها در بازبینی دسکتاپ موفق |
| UI-07 | مالی و زمان‌بندی | تقویم شمسی، ساعت، وضعیت نوبت، مبلغ و فاکتور در RTL صحیح هستند. | تقویم، فاکتور و فرم ثبت نوبت در بازبینی دسکتاپ موفق |
| REG-01 | تست | `php artisan test` بدون خطا اجرا می‌شود. | موفق — ۳۸ تست و ۱۵۳ assertion |
| REG-02 | کیفیت PHP | Pint، Composer validate/audit و `git diff --check` موفق هستند. | موفق — Pint روی ۱۲۷ فایل، Composer validate/audit و diff check |
| REG-03 | build | Blade view cache و Vite build موفق هستند. | موفق — Blade cache و Vite build؛ هشدار مسیر public فونت در build غیرمسدودکننده و فایل‌ها موجودند |
| REG-04 | Smoke Test | نصب از ZIP تمیز با Composer بدون dev، APP_KEY، migration و optimize:clear موفق است. | نسخهٔ جاری install smoke داشت؛ Release جدید پس از package باید مجدداً smoke شود |
