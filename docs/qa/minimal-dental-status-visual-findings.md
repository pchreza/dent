# بازبینی بصری صفحهٔ مینیمال وضعیت دندان‌ها

**محیط:** Laravel محلی روی `127.0.0.1:8000`، رابط فارسی RTL، Tenant نمایشی و بیمار `DEMO-001`.

تجربهٔ قبلی تصویر فک، SVG، کنترل‌های فک و پنل «داستان درمان دندان» از صفحه حذف شده است. صفحهٔ جدید با عنوان «وضعیت دندان‌ها» فقط خلاصهٔ دو عددی، فهرست آخرین وضعیت هر دندان، فرم ثبت سریع و جدول تاریخچهٔ کامل را نمایش می‌دهد.

در بازبینی مستقیم، ۷ دندان دارای وضعیت به‌صورت فهرست خوانا نمایش داده شدند. هر ردیف شامل کد دندان، نام کوتاه آناتومیک فارسی، وضعیت، سطح، یادداشت، تاریخ شمسی و عملیات «ثبت وضعیت» و «طرح درمان» بود. فرم ثبت سریع نیز دندان ۱۶ و سطح جونده را از query string دریافت و در فرم انتخاب کرد. هیچ تصویر فک، SVG، stepper یا timeline قبلی در صفحه باقی نمانده است.
