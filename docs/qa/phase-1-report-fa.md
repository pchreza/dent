# گزارش فاز یک — اسکلت فنی، نصب و امنیت پایه

**وضعیت:** آمادهٔ عبور به فاز دو

## 1. خروجی‌های پیاده‌سازی‌شده

در این فاز پروژه از مخزن خالی به اسکلت Laravel 12 با PHP 8.3 تبدیل شد. Migration هویت برای موبایل، نام کاربری، وضعیت حساب، سوپرادمین و نشست‌ها بازطراحی شد. Migration هستهٔ Tenant، نقش، مجوز، عضویت، تنظیمات پلتفرم و رویداد ممیزی اضافه شد.

ویزارد نصب وب‌محور ساخته شد. ویزارد پیش‌نیازهای PHP و افزونه‌ها را نمایش می‌دهد، تنظیمات اولیه و حساب سوپرادمین را می‌گیرد، Migration و Seeder را اجرا می‌کند، تنظیمات محصول و برند را ذخیره می‌نماید و پس از موفقیت با `installed.lock` قفل می‌شود.

ورود با شمارهٔ موبایل یا نام کاربری، رمز عبور، Rate Limiting، رد حساب غیرفعال، بازسازی نشست، خروج امن و داشبورد اولیه ساخته شد. Middlewareهای `installed`، `not_installed` و `tenant` و سرویس‌های InstallationState، TenantContext، NormalizeIdentifier و PlatformSettings نیز اضافه شدند.

رابط اولیه فارسی/RTL شامل Layout مشترک، Sidebar، صفحهٔ نصب، صفحهٔ ورود و داشبورد ساخته شد. فونت Vazirmatn به‌صورت آفلاین در `public/fonts` قرار گرفت و CSS با توکن‌های Design System، Focus، Responsive، Reduced Motion و CSS منطقی نوشته شد.

## 3. خطاهای کشف‌شده و اصلاح‌شده

در نخستین اجرای تست‌ها، درایور SQLite در محیط توسعه وجود نداشت؛ PHP 8.3 SQLite نصب شد و Migration تستی موفق شد. سپس نبود Vite manifest باعث پاسخ 500 در صفحهٔ نصب شد؛ Build فرانت‌اند اجرا و manifest تولید شد. درخواست‌های POST تستی به‌دلیل CSRF فعال 419 می‌دادند؛ CSRF فقط در تست‌های Feature و نه در برنامهٔ تولید، غیرفعال شد. یک تست پیش‌فرض ریشه نیز از انتظار 200 به رفتار ریدایرکت واقعی اصلاح شد.

## 4. Issue باقیمانده

در آزمون دستی اولیه، سربرگ قبل از اتصال Resolver تنظیمات، مقدار پیش‌فرض Laravel را نشان می‌داد. `PlatformSettings` ساخته و به Layout متصل شد تا نام محصول و برند ذخیره‌شدهٔ نصب نمایش داده شوند. این اصلاح در تست‌های Regression و Build نهایی قرار گرفت.

Vite برای فایل فونت واقع در `public/fonts` هشدار اطلاعاتی می‌دهد که مسیر در زمان Build resolve نشده و در Runtime خوانده خواهد شد. این رفتار برای دارایی public صحیح است و مانع Build نیست؛ در فاز رابط می‌توان فونت را به pipeline Vite منتقل کرد تا هشدار حذف شود.

## 5. محدودیت‌های آگاهانهٔ این فاز

این فاز هنوز صفحهٔ مدیریت کلینیک، شعبه، کاربران، CRUD نقش/مجوز، پروندهٔ بیمار، نمودار دندان، نوبت، فاکتور و اعلان عملیاتی را پیاده‌سازی نکرده است. این موارد طبق نقشه‌راه در فازهای بعدی اضافه می‌شوند. مدل دامنه و قراردادهای آن‌ها در فاز صفر ثبت شده است.
